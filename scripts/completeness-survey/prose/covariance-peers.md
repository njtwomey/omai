## R packages and their Python and JavaScript peers

The R packages practitioners expect, with the peer a Python or JavaScript user would reach for. Function names come from the CRAN reference-manual
indexes (read on 2026-11-09). The robustbase index was only read to the 100,000-character cut-off, so its list is the scatter and scale part.
"Peer" means the nearest package that is installable from PyPI or npm and that was looked at here, not an equivalent.

JavaScript peers (from memory, not read): simple-statistics (`sampleCovariance`, `sampleCorrelation` of two arrays), jstat (`covariance`, `corrcoeff`), ml-matrix
(`covariance`, `correlation` of a matrix) and ml-pca (PCA). None has shrinkage, a robust or a sparse estimator, so for a JavaScript user omai is already the whole of the shelf
that exists; the gaps below are gaps against R and Python, not against a JavaScript library.
