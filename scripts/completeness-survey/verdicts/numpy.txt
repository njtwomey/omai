# numpy: the array namespace behind `tensor` (and `numerics/linalg`, `numerics/fourier`, `random`). Introspected from the installed
# numpy (callable, non-class names of the top level, numpy.linalg, numpy.fft and the methods of numpy.random.Generator).
# omai's `tensor` is a differentiable array with torch-shaped names (`concat`, `stack`, `neg`, `sub`, `floorDiv`, `searchsorted`),
# so many numpy names match by concept, not by name. Judged by group, not one by one: the dtype, printing, file and C-API
# plumbing of numpy is out of scope. The groups name what is genuinely missing.
