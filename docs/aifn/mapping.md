# Mapping AIFN to omai, for anyone porting a note

The alias map is `scripts/aifn-usage/aliases.json`: 367 renamed or moved symbols, 125 covered by a differently shaped API,
10 not a capability, 5 same-named omai symbols that are a different thing, and the module map below. Every entry has a
reason. The full list as the notes meet it (most used first) is `data/aliases.md`.

## The prefix change

| AIFN                                                                       | omai                                                                                                                                                                                                                                                    |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `aifn-compute/<family>/<module>`                                           | `omai-engine/<domain>`, usually flatter: the family folders are gone (`foundation/tensor` is `tensor`, `numerics/special` is `numerics/special`, `learning/metrics` is `metrics`, `probability/stats` is `stats`, `probability/tests` is `stats/tests`) |
| `aifn-methods/<area>/<method>`                                             | the library domain that owns the method (`learn`, `linear`, `cluster`, `trees`, `ensembles`, `svm`, `tune`, `datasets`, ...). There is no methods layer: a named method is a library estimator, and a demonstration is a page that composes it          |
| `aifn-render` (root) and `aifn-render/<viz,layout,state,controls,diagram>` | `omai-render/<charts,figure,react,theme,layout,structures,maths,gym>`; the shape of the API differs, see `gaps.md`                                                                                                                                      |
| `aifn-render/ui/*`, `cn`                                                   | nothing: shadcn primitives; an app brings its own                                                                                                                                                                                                       |

Sub-folders of the AIFN families that omai names in a different place:
- `numerics/special` keeps its name; the normal and Student-t functions are scipy's (`ndtr`, `ndtri`, `stdtr`,
  `stdtrit`); the log-gamma is `lgamma`, the regularised beta `betainc`, the regularised gamma `gammainc`.
- AIFN `learning/*` splits into `learn` (estimators, pipelines, calibration, conformal, multiclass), `metrics`, `losses`,
  `kernels`, `explain`, `rules`, `patterns` (subgroups, itemsets) and `learn/model-selection` (validation, tests of
  comparison, nested CV).
- AIFN `inference/*` is `pgm` (exact and message-passing), `dynamics/filtering` (Kalman, BOCPD), `sampling` and
  `probprog`.
- AIFN `nn/*` is `nn` (layers, functional, pooling, quantisation, describe) and `nn/blocks` (the named blocks: operators,
  state-space, Hopfield, experts, graph, vision).
- AIFN `signal/*` is `signal`, `signal/audio`, `signal/image`, `timeseries` (matrix profile, motifs) and `optim` (the
  sparse-recovery solvers: basis pursuit, matching pursuit, hard thresholding).

## The conventions that change a call

| AIFN                                                                                                       | omai                                                                                                                                                                                                   |
| ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `stream(seed)`, `child(s, 'name', 3)`, `normal(s, mean, sd, { shape })`: a mutable counter                 | immutable keys: `key(seed)`, `foldIn(k, 3)`, `keyFromPath`, `normal(k, shape, { loc, scale })`; or a `Generator`. The same seed gives different numbers, so a figure that quotes a drawn value changes |
| distribution classes `Normal`, `Binomial`, ...                                                             | factory functions `normal`, `binomial` of `omai-engine/dists`                                                                                                                                          |
| `dataset(x, y)` and capability-typed models (`Fitted`, `Predicts`, `Decides`)                              | sklearn-style estimators of `omai-engine/learn` and a `Dataset` record of `omai-engine/data`                                                                                                           |
| `fooSteps(...)` and `fooRun(...)`: a function returning a stepped trace                                    | `fooAlgorithm` (an `Algorithm`) run by `runAlgorithm` or a `Session`; the estimator is configured with it                                                                                              |
| `trace(alg, n)`, `run(alg, n)`, `live(alg)`                                                                | `runAlgorithm`, `Session`, `useLiveRun`                                                                                                                                                                |
| `linearRegression`, `logisticRegression`, `glm`, `elasticNet`                                              | one `linearModel` with a family and a penalty (`fitLinear`); a model is an objective and the solver is a slot                                                                                          |
| `kNearestNeighbours`, `supportVectorMachine`, `decisionTree`, `randomForest`, `adaBoost`                   | `kNeighboursClassifier`, `svc`, `decisionTreeClassifier`, `randomForestClassifier`, `adaBoostClassifier`                                                                                               |
| names in the AIFN style (`regularisedBeta`, `logGamma`, `standardDeviation`, `welchTTest`, `binomialTest`) | scipy and sklearn names (`betainc`, `lgamma`, `std`, `ttestInd`, `binomTest`)                                                                                                                          |
| `Figure`, `Plot`, `useAxis`, `Curve`, `Points`, `Handle`, `useFigureState`                                 | see `gaps.md`, "What costs the most to port"                                                                                                                                                           |
